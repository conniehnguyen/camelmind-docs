Welcome to CamelMind! 👋

CamelMind is an open-source docs-as-code platform built on Next.js for building product documentation, API references, internal knowledge bases, and developer portals.

Write content in Markdown and MDX, organize your navigation with YAML, and deploy anywhere—from Vercel and Docker to any Node.js host or static CDN.

Whether you're documenting a public API, publishing internal documentation, or maintaining a versioned product manual, CamelMind scales from small documentation sites to enterprise developer portals.
