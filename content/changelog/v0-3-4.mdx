## New features

### Docusaurus and MkDocs migration

You can now migrate an existing Docusaurus or MkDocs site to CamelMind with a single command:

```bash
npx camelmind@latest migrate path/to/your-docs-repo
```

The migration automatically detects your framework, converts Markdown to MDX, builds navigation from your existing structure, and generates a report for anything that needs manual attention. Your original repository remains unchanged.

For best results, migrate your **content and information architecture first**, then recreate customizations using CamelMind's native features.

See the [Docusaurus and MkDocs migration guide](/getting-started/migrate-from-docusaurus-mkdocs) for the complete process, options, customization guidance, and validation checklist.



## Improvements

### Added the Info type to Callout

The Callout component now supports an `info` type for highlighting helpful or informational content.

```mdx
<Callout type="info">
This is an informational callout.
</Callout>
```

<Callout type="tip" title="Updating to a new version">

Use the `update` command to upgrade an existing CamelMind site to the latest platform version. Choose the option that best fits your workflow:

| Option | Command |
| --- | --- |
| Update your project to the latest CamelMind version | `npx camelmind@latest update` |
| Preview the files that would change without modifying your project | `npx camelmind@latest update --dry-run` |
| Update project files without running `npm install` | `npx camelmind@latest update --no-install` |
| Preserve a customized file during the update | `npx camelmind@latest update --ignore-file app/page.tsx` |

</Callout>
