# Static Export

CamelMind supports a fully static export mode — no Node.js server required at runtime. The output is a folder of HTML, CSS, and JS files you can serve from any CDN, S3 bucket, or local machine.

## When to use static export

| Use case | Recommendation |
|---|---|
| GitHub Pages / S3 / Cloudflare Pages | Static export |
| Offline documentation package | Static export |
| Auth-gated pages | **Not** static export — requires a server |
| API reference with live requests | **Not** static export — requires a server |
| Vercel / Netlify / Docker | Server mode (default) — more capable |

<Callout type="warning">
Static export bypasses authentication. All pages are included in the build and accessible to anyone who has the files. Do not use static export for sites with role-gated content.
</Callout>

## Building a static export

Set the `OFFLINE_MODE` environment variable and run the build:

```bash
OFFLINE_MODE=true npm run build
```

The output is written to `out/`. Serve it locally with any static file server:

```bash
npx serve out/
```

## Offline ZIP package

The `build-offline.sh` script wraps the static export into a self-contained ZIP with launcher scripts for Mac, Linux, and Windows:

```bash
./scripts/build-offline.sh v1.0
```

**Output:** `offline-builds/my-docs-v1.0-offline.zip`

The ZIP includes:
- Pre-rendered static HTML for all pages
- Pre-built search index (`search-index.json`)
- `launch.sh` (Mac/Linux) and `launch.bat` (Windows) launcher scripts

### How users open it

| Platform | Steps |
|---|---|
| Mac / Linux | Unzip, then double-click `launch.sh` or run `./launch.sh` |
| Windows | Unzip, then double-click `launch.bat` |

The launcher starts a local HTTP server on port **8765** and opens the site in the default browser automatically.

## Differences in offline mode

| Feature | Server mode | Static export |
|---|---|---|
| Authentication | Keycloak / OIDC | Bypassed — all pages public |
| Search | `/api/search` (server) | `search-index.json` (pre-built) |
| View/Download Markdown | Available | Hidden (no server) |
| Download PDF | Available if configured | Available (static link) |
| Offline download link | Shown for logged-in users | N/A |

## Search in offline mode

The pre-built search index is generated by the `build-search-index.ts` script, which runs automatically as part of `build-offline.sh`. To generate it manually:

```bash
npx tsx scripts/build-search-index.ts
```

This writes `public/search-index.json`. The search modal (`⌘K`) uses this file when `/api/search` is unavailable.

## Static hosting

After running `OFFLINE_MODE=true npm run build`, deploy the `out/` folder to any static host:

**GitHub Pages:**
```bash
gh-pages -d out
```

**Cloudflare Pages / Netlify:** point the build output directory to `out` in your hosting dashboard.

**AWS S3:**
```bash
aws s3 sync out/ s3://my-bucket/ --delete
```
