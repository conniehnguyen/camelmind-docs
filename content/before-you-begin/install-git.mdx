Good news—you do  not need Git to start using CamelMind.

You can create a documentation site, edit pages, and preview your changes locally without installing Git. You'll only need it when you're ready to publish your site online, back up your work, or collaborate with others.

If you're just exploring CamelMind, feel free to skip this guide for now.

---

## Understanding Git for version control

Git is a command-line tool that tracks changes to your project files over time.

Think of Git as a **save history** for your entire project. Every time you reach a milestone, you save a snapshot (called a **commit**) and return to it later if something goes wrong.

Git allows you to:

- Save your project history
- Undo mistakes
- Review changes over time
- Collaborate with teammates

---

## Comparing Git versus GitHub

While people often mention these tools together, they fulfill distinct roles:

| Tool | What it does |
| --- | --- |
| **Git** | Tracks file changes on your computer. |
| **GitHub** | Stores your Git repository online so you can back up your work, collaborate with others, and deploy your site. |

Think of Git as a physical notebook and GitHub as cloud backup for that notebook.

## Deciding if you need to install Git for CamelMind

Review this requirements breakdown to determine whether your CamelMind documentation workflow requires a local Git installation right now:

| If you want to...              |      Git required?     |
| ------------------------------ | :--------------------: |
| Create a CamelMind site        |          ❌ No          |
| Edit documentation             |          ❌ No          |
| Preview your site locally      |          ❌ No          |
| Keep a history of your changes |      ✅ Recommended     |
| Collaborate with teammates     |          ✅ Yes         |
| Deploy with GitHub             |          ✅ Yes         |
| Deploy to Vercel or Netlify    | ❌ No (but recommended) |

Most new users learn Git after building their first documentation site.

## Installing Git on your operating system

When you are ready to set up Git, select your operating system below:

<Tabs>
<Tab label="macOS">

macOS often includes Git by default.

To check your system, open a terminal and run:

```bash
git --version
```

If your system lacks Git, macOS prompts you to install the Xcode Command Line Tools.

Alternatively, install Git using Homebrew:

```bash
brew install git
```

</Tab>

<Tab label="Windows">

Download the installer directly from [git-scm.com](https://git-scm.com/) and run setup using the default settings.

</Tab>

<Tab label="Linux">

Install Git using your distribution's package manager, for example:

```bash
sudo apt install git
```

</Tab>
</Tabs>

---

## Verifying your Git installation

Confirm that your terminal recognizes Git by running:

```bash
git --version
```

If your terminal displays a version number, your installation succeeded.

---

## Configuring Git for first-time setup

Provide Git with your name and email address so Git can attribute each commit to you:

```bash
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
```

<Callout type="tip">
If you plan to use GitHub, enter the same email address registered to your GitHub account to link your commits automatically.
</Callout>
