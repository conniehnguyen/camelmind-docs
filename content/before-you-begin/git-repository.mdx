You do not need an online Git repository to use CamelMind. You can create, edit, and preview your documentation entirely on your local machine.

Once you are ready to back up your work, collaborate with others, or publish your site online, store your project in a Git hosting service such as **GitHub**, **GitLab**, or **Bitbucket**.

This guide focuses on GitHub because it offers free accounts, a beginner-friendly interface, and broad support across deployment platforms.

---

## Why use a Git hosting service

Hosting your Git repository online gives you several benefits:

- Back up your project
- Access your work from other computers
- Collaborate with teammates
- Connect your repository directly to deployment platforms like Vercel

If you are just exploring CamelMind, feel free to skip this guide and return later.

---

## Differences between Git and GitHub for documentation management

Understanding the difference between Git and GitHub helps you choose the right version control and repository hosting setup for your CamelMind documentation project:

| Tool | What it does |
| --- | --- |
| **Git** | Tracks local file changes on your computer. |
| **GitHub** | Stores and hosts your Git repository online in the cloud. |
| **GitLab** | Offers an alternative Git hosting platform with similar features. |
| **Bitbucket** | Integrates Git repository hosting with Atlassian products like Jira. |

CamelMind works seamlessly with any Git hosting provider.

---

## Create a GitHub account

If you are new to Git hosting, GitHub provides a great starting point.

1. Visit [https://github.com/signup](https://github.com/signup).
2. Create a free account.
3. Create a new repository for your CamelMind project.

Once you set up your repository, push your local project using Git:

```bash
git add .
git commit -m "Initial commit"
git push
```

---

## Deploying your CamelMind site from a Git repository

Most cloud hosting platforms offer automated build pipelines to deploy your CamelMind site whenever you commit and push updates to your remote Git repository.

Popular deployment options include:

- **Vercel** (recommended for most users)
- **Netlify**
- **Cloudflare Pages**
- Your own Node.js or Docker infrastructure

Check the deployment guides for detailed instructions.

<Callout type="tip">
Deployment platform support extends beyond GitHub—many platforms also support GitLab, Bitbucket, or direct deployments via their CLI tools.
</Callout>
