Before you create your first CamelMind site, install **Node.js**.

NO need to worry if you have never used Node.js before—you do not need to learn JavaScript or understand how it works. Think of it as the engine powering CamelMind behind the scenes.

Once you install Node.js, you have everything you need to create, preview, and publish your documentation site.

---

## Understanding the role of Node.js in CamelMind

Node.js serves as the core runtime environment that enables your local machine to execute JavaScript applications outside of a web browser.

Next.js powers CamelMind and relies on Node.js to:

- Create a new CamelMind site
- Preview your documentation locally while you edit
- Build your site for production deployment

You do not need to write JavaScript to use CamelMind—just install Node.js once, and CamelMind handles the rest.

---

## Understanding npm and package management

When you install Node.js, your system automatically receives **npm** (Node Package Manager).

npm downloads and manages the software packages that CamelMind requires. Throughout this documentation, you will run standard npm commands such as:

```bash
npm install
npm run dev
```

These commands install your project dependencies and launch the local development server.

<Callout type="note">
CamelMind also supports package managers such as **pnpm** and **Yarn**. If you are just starting out, stick with **npm**—Node.js includes it by default, requiring no additional setup.
</Callout>

## Installing Node.js on your operating system

Select your operating system below and install the latest **LTS (Long-Term Support)** version of Node.js:

<Tabs>
<Tab label="macOS">

Download the **LTS** installer from [nodejs.org](https://nodejs.org/) and follow the installation wizard.

If you use Homebrew, install Node.js directly from the Terminal:

```bash
brew install node
```

</Tab>

<Tab label="Windows">

Download the **LTS** installer from [nodejs.org](https://nodejs.org/) and run the setup wizard using default settings.

</Tab>

<Tab label="Linux">

Install Node.js using your distribution's package manager, or set it up with **nvm** (recommended if you work on multiple JavaScript projects):

```bash
curl -o- [https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh](https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh) | bash
nvm install --lts
```

</Tab>
</Tabs>

<Callout type="tip">
Always select the **LTS (Long-Term Support)** release. It provides maximum stability, and the CamelMind team tests all releases against it.
</Callout>

## Verifying your Node.js and npm installation

Confirm that your terminal recognizes Node.js and npm by running:

```bash
node --version
npm --version
```

If both commands return a version number, your setup is complete.

CamelMind requires **Node.js 20 or later**.

<Callout type="tip">
If your terminal returns a `command not found` error, restart your terminal and try again. If the issue continues, reinstall Node.js using the installer above.
</Callout>

## Frequently asked questions about Node.js

<Details summary="Do I need to know JavaScript?" id="need-to-know-js">

No. CamelMind uses Markdown and MDX for content creation. Node.js simply executes the underlying tools that build and serve your site.

</Details>

<Details summary="Do I need to install npm separately?" id="need-npm">

No. Node.js installs npm automatically during setup.

</Details>

<Details summary="Should I install pnpm or Yarn instead?" id="need-install-pnpm">

Not unless you already use them. npm works perfectly and offers the simplest path for new users.

</Details>

<Details summary="Can I install multiple versions of Node.js?" id="multiple-versions-node">

Yes. If you work on multiple JavaScript projects, consider a version manager such as **nvm** (macOS/Linux) or **fnm** (cross-platform). For most users, installing the latest LTS version satisfies all requirements.

</Details>
