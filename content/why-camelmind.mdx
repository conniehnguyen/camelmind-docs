CamelMind is an open-source, self-hostable documentation platform for teams that need modern developer documentation without the costs or limitations of hosted documentation SaaS.

Compared with today's documentation platforms, CamelMind combines:

- Open-source ownership
- API documentation
- Private documentation
- Offline documentation
- LLM-ready documentation
- AI-assisted authoring

Unlike managed SaaS platforms, you own your documentation stack and can deploy it anywhere. Compared with traditional static site generators, CamelMind includes many developer portal capabilities out of the box.

## When CamelMind is the right choice

CamelMind is built for teams that want the flexibility of docs-as-code without giving up the capabilities of a modern documentation platform.

Choose CamelMind if your team wants to:

- Own and self-host your documentation instead of relying on a hosted SaaS.
- Publish both public and private documentation from the same platform.
- Render multiple API references from different OpenAPI specifications in a single documentation site.
- Export documentation as offline ZIP packages or a complete PDF for customers in restricted environments.
- Control access with built-in OIDC authentication and page-level RBAC.
- Write documentation that's optimized for both humans and AI assistants with built-in `llms.txt`, Markdown exports, and upcoming AI authoring tools.

<Callout type="tip" title="CamelMind may not be the best fit if...">

Every documentation platform has a different focus. CamelMind may not be the best choice if:

- Your primary requirement is automatic SDK generation, where tools like Fern specialize.
- You prefer a fully managed SaaS platform and don't want to host your own documentation.

</Callout>

## Why teams choose CamelMind

Choosing a documentation platform often means making a trade-off.

Open-source tools give you complete ownership and flexibility, but advanced capabilities like API references, authentication, offline exports, and AI-ready documentation typically require a collection of plugins and custom integrations.

Hosted documentation platforms offer a polished, all-in-one experience, but they come with subscription costs, limited deployment options, and less control over your documentation stack.

CamelMind is designed to bridge that gap.

It combines the ownership and flexibility of an open-source, self-hostable platform with many of the capabilities expected from modern documentation platforms—including API documentation, private documentation, offline deliverables, and AI-native documentation workflows.

Instead of stitching together plugins or upgrading to expensive SaaS plans, you get a unified platform built for creating documentation that serves both human readers and AI systems.
