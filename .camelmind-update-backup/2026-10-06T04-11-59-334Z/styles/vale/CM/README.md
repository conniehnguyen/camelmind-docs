# CM

## About

Custom Vale rules authored for CamelMind (not vendored from an external style package). Add rules here when a check is specific to CamelMind's house style and doesn't belong in one of the third-party packages under `styles/vale/`.

## Styles

### SingleUseAcronym

- If an acronym is used only once in a document, spell out the full term and omit the acronym in parentheses.
- Only introduce the acronym in parentheses if the term is used multiple times in the same document.

For example, if the term appears only once, write "Application Programming Interface." Don't write "Application Programming Interface (API)."
